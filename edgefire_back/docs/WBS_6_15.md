### 아키텍처 / ERD
`HW -> POST /telemetry/multimodal -> telemetry -> telemetry_gas_logs / sensor_nodes / alerts -> Redis Pub/Sub -> WS -> FE`; 옵션 `?queued=true`는 Redis Stream `edgefire:telemetry:ingest` → Celery drain → DB commit → publish → XACK. 기본 direct 경로는 원격 팀 호환용으로 유지. `jobs`는 DB에 저장되며 AI worker가 lease로 가져감. `forecasts` 1:N `forecast_polygons`; `wui_zones` 1:N `sensor_nodes` (논리 관계); `wui_assets` 공간교차 대상; `ptz_commands`, `vision_metadata`, `dispatch_log` 별도 이력. 센서 로그의 `telemetry.id`는 생성 이벤트 ID, 중복키 `(node_id,boot_id,seq)`.

### SRS / ICD 추가
- 모든 외부 API 인증은 기존 역할별 키; 브라우저 REST는 Next.js 서버 프록시, WS는 짧은 티켓. TLS 보호는 사설 VPN 터널을 전제로 함.
- `GET /api/v1/zones`, `/zones/{zone_id}`, `/sensors`, `/sensors/nearby?latitude=&longitude=&radius_m=`. 구역·자산 실제 입력 전 `seed_demo_geo.py`는 **demo**만 생성. `/sensors`는 수신 센서 목록, nearby는 등록 카메라 포함.
- MQTT topic `edgefire/{node_id}/telemetry`, QoS 1, UTF-8 JSON = 기존 Telemetry schema. TLS broker/인증 필요. 실패 파일 `mqtt_pending.jsonl`은 수동 검사/재전송 필요. MQTT 미설치라면 HTTP 직결 사용.
- `GET /api/v1/telemetry/history?hours=1|24&node_id=...`; `GET /api/v1/storage/sync?after_created=...&after_id=...&limit=...`는 페이지 cursor 반환. DB 쓰기 직렬화 및 단조 증가 created 값으로 동시 커밋 gap 방지 설계. PostgreSQL 실환경 검증 전이며 FE overlap/full refresh와 event_id dedup 유지. 0누락 주장 금지.
- Redis `node:status:{node_id}` Hash (`timestamp`, `payload`, TTL 60s); `edgefire.events` Pub/Sub. Stream은 처리 성공 후 삭제, 실패 메시지는 dead-letter 또는 pending, 배치 30. 운영 중 모니터링·백업 필요.
- `POST /api/v1/camera/ptz/command` action=auto + camera/target coordinates 또는 left/right/up/down/zoom_in/zoom_out/stop. 실제 전송 안 함. `POST /api/v1/vision/metadata` bbox xyxy, score, model_id, optional snapshot URL (저장만, 자동 다운로드 안 함).
- `GET /api/v1/prediction/diffusion` latest 또는 forecast_id; `/.../{id}/impact`, `/.../{id}/tiles/{z}/{x}/{y}.mvt` PostGIS 필수. `POST /api/v1/storage/forecast` 기존 AI 보조 서비스 입력 그대로. 10/20/30분 결과를 저장하되 모델 정확도 검증 아님.
- `POST /api/v1/dispatch/simulate` channel=119|forest|relay|cbs|alimtalk, event_id. **항상 모의 처리**. `/api/v1/dispatch/stats` 전파 통계(실제 발송 아님).
- DB DDL은 `app/db.py`, `app/wbs.py`의 init으로 멱등 생성; 별도 `sql/inspect_postgis.sql` 확인용. native UTC partition은 `ensure_partition`에서 생성. 실제 10ms/50ms/1000TPS/2000 pushes 목표 미측정.
